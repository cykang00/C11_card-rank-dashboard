# 네이버 신용카드 키워드 트래커

네이버 검색광고 키워드 수치(검색량·경쟁도·예상입찰가)를 수집해 구글 시트에 누적하고, Streamlit 대시보드로 비교·분석한다.

## 현재 상태
- ✅ 대시보드 (샘플 데이터로 동작)
- ⏳ 수집기(검색광고 API + 구글 시트 누적): 키 발급 후 별도 구현

## 대시보드 실행 (샘플 데이터)

```bash
cd naver-keyword-tracker
uv run streamlit run dashboard.py
```

브라우저 `localhost:8501` 에서 확인:
1. **키워드 비교 표 + 검색량 막대** (최신 수집일)
2. **검색량 vs 1위 입찰가 산점도** — 저비용·고검색 기회 탐색
3. **선택 키워드 추이 라인** — 날짜별 검색량·1~3위 입찰가 변화

## 테스트

```bash
uv run pytest -q
```

## 구조

| 파일 | 책임 |
|------|------|
| `core/schema.py` | 표준 컬럼 정의·검증 |
| `core/data_source.py` | 샘플 CSV(추후 구글 시트) → 표준 DataFrame |
| `core/charts.py` | 차트 준비 순수 함수 |
| `dashboard.py` | Streamlit 화면 조립 |
| `sample_data.csv` | 5개 키워드 × 3일 샘플 |

## 데이터 정확도
- 샘플 데이터는 데모용 임의값입니다. 실데이터 연동 후 검색광고 API 원본으로 대체됩니다.
- 검색량 `< 10` 보정값·비노출 입찰가(null)는 추정/결측으로 표기 예정.
